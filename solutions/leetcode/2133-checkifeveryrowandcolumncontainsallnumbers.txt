<p>An $n \times n$ matrix is valid if every row and every column contains all the integers from $1$ to $n$ (inclusive).</p>
<p>Given an $n \times n$ integer matrix <code>matrix</code>, return <code>true</code> if the matrix is valid. Otherwise, return <code>false</code>.</p>
<h2>How the Solution Works</h2>
<p>We check each row and column of the $n \times n$ matrix to verify that it contains all integers from $1$ to $n$:</p>
<ol>
<li>We iterate through each index $i$ from $0$ to $n - 1$.</li>
<li>For each $i$, we initialize two sets: one for the current row $i$ and one for the current column $i$.</li>
<li>We traverse the elements of the row and column using a secondary index $j$ from $0$ to $n - 1$.</li>
<li>We verify that each visited element is within the range $[1, n]$ and has not been seen yet in the current row/column.</li>
<li>If any validation fails, we immediately return <code>false</code>.</li>
<li>If we check all rows and columns successfully, we return <code>true</code>.</li>
</ol>
<h2>Complexity</h2>
<ul>
<li><strong>Time Complexity:</strong> $O(N^2)$ where $N$ is the dimension of the matrix, as we must visit each of the $N^2$ elements in the matrix once.</li>
<li><strong>Space Complexity:</strong> $O(N)$ auxiliary space to store elements of a single row and column in hash sets during validation.</li>
</ul>
