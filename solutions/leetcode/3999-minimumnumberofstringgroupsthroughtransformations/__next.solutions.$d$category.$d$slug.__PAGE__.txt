3:T796,<h1>Minimum Number of String Groups Through Transformations</h1>
<p>You are given an array of strings <code>words</code>. A transformation on a string <code>s</code> is defined by:</p>
<ol>
<li>Extracting the subsequence of characters at even indices (<code>E</code>) and odd indices (<code>O</code>).</li>
<li>Independently cyclically shifting <code>E</code> and <code>O</code> by any number of positions to the right.</li>
<li>Reconstructing the string by placing the shifted characters back into their respective even/odd positions.</li>
</ol>
<p>Two strings are equivalent if one can be transformed into the other by a single transformation. The goal is to partition the <code>words</code> into the minimum number of groups such that all strings in a group are equivalent.</p>
<h2>How the Solution Works</h2>
<p>We can solve this problem in $O(N \cdot L)$ time with an <strong>optimal approach</strong>:</p>
<ul>
<li>For each word, we extract the characters at even indices (<code>E</code>) and odd indices (<code>O</code>) to form two separate subsequences.</li>
<li>We find the lexicographically smallest cyclic rotation (canonical representation) for <code>E</code> and <code>O</code> independently (using Booth&#39;s algorithm or linear rotation comparisons).</li>
<li>We combine the two canonical sequences into a unified key, e.g. <code>(canonical_E, canonical_O)</code>.</li>
<li>By putting these keys in a hash set, the size of the set gives the minimum number of groups.</li>
</ul>
<h2>Complexity</h2>
<ul>
<li><strong>Time Complexity:</strong> $O(N \cdot L)$ where $N$ is the number of words and $L$ is the max length of a word.</li>
<li><strong>Space Complexity:</strong> $O(N \cdot L)$ to store the canonical representations in a hash set.</li>
</ul>
<p>⚡ <strong>Optimal Approach</strong></p>
