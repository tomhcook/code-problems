3:T686,<h1>Add Two Numbers</h1>
<p>You are given two non-empty linked lists representing two non-negative integers. The digits are stored in reverse order, and each of their nodes contains a single digit. Add the two numbers and return the sum as a linked list.</p>
<h2>How the Solution Works</h2>
<p>We can solve this problem in $O(N)$ time with an <strong>in-place</strong> optimal approach:</p>
<ul>
<li>We traverse both linked lists node-by-node, adding corresponding digits along with a <code>carry</code> from the previous sum.</li>
<li><strong>In-place Optimization (Memory Efficient)</strong>: Instead of allocating memory for a new list ($O(N)$ auxiliary space), we reuse the nodes of the input list <code>l1</code> to store the sum values. </li>
<li>If <code>l1</code> is shorter than <code>l2</code>, we dynamically redirect the traversal pointer to reuse the remaining nodes of <code>l2</code>.</li>
<li>We allocate a new node only in the rare case of a final carry overflow at the end (e.g. $99 + 1 = 100$). This ensures we avoid extra garbage collection and keep the memory footprint extremely low.</li>
</ul>
<h2>Complexity</h2>
<ul>
<li><strong>Time Complexity:</strong> $O(N)$ where $N = \max(\text{len}(l1), \text{len}(l2))$, as we traverse the nodes of the lists at most once.</li>
<li><strong>Space Complexity:</strong> $O(N)$ to represent the return value list, but <strong>$O(1)$ Auxiliary Space</strong> because we reuse the input nodes in-place rather than allocating a new list.</li>
</ul>
<p>⚡ <strong>Optimal Approach</strong> (Minimal Memory Footprint)</p>
