3:T622,<h1>Number of Unique XOR Triplets II</h1>
<p>Given an integer array <code>nums</code>, a XOR triplet is defined as the XOR of three elements <code>nums[i] XOR nums[j] XOR nums[k]</code> where <code>i &lt;= j &lt;= k</code>.</p>
<p>Return the number of unique XOR values that can be formed by these triplets.</p>
<h2>Difficulty: Medium</h2>
<h2>How the Solution Works</h2>
<p>Given the constraints ($N \le 1500$, $nums[i] \le 1500$):</p>
<ol>
<li><strong>Bounded XOR Value:</strong> The maximum value in <code>nums</code> is 1500. The next power of two is 2048. Since XORing numbers under 2048 results in a value under 2048, all possible XOR triplet values will be strictly less than 2048.</li>
<li><strong>Step 1 (Pairs):</strong> We use a boolean array <code>s1</code> of size 2048 to track all possible XORs of two elements <code>nums[i] ^ nums[j]</code> for $i \le j$.</li>
<li><strong>Step 2 (Triplets):</strong> We use another boolean array <code>s2</code> of size 2048 to track all possible XORs of three elements. For every XOR value <code>x</code> in <code>s1</code> that is possible, and for every <code>num</code> in <code>nums</code>, we set <code>s2[x ^ num] = True</code>.</li>
<li><strong>Result:</strong> The sum of <code>True</code> values in <code>s2</code> is our answer.</li>
</ol>
<h2>Complexity</h2>
<ul>
<li><strong>Time Complexity:</strong> $O(N^2 + N \cdot M)$ where $N$ is the length of <code>nums</code> and $M = 2048$ (the maximum possible XOR value).</li>
<li><strong>Space Complexity:</strong> $O(M)$ to store the boolean arrays.</li>
</ul>
