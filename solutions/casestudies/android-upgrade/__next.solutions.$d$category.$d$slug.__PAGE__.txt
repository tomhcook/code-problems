3:Td17,<h1>Android 16 &amp; .NET 10 Migration across Multi-App Ecosystem (HWM)</h1>
<p>An active engineering initiative at <strong>HWM</strong> focusing on migrating multiple enterprise applications from .NET 9 to .NET 10, alongside upgrading a critical cross-platform mobile application to support Android 16 (SDK 36).</p>
<h2>Technical Showcase</h2>
<ul>
<li><strong>Role</strong>: Mobile &amp; Systems Developer (C# / .NET)</li>
<li><strong>Architecture</strong>: .NET MAUI Mobile App, ASP.NET Core Web APIs, Background Services</li>
<li><strong>Backend &amp; Infrastructure</strong>: C#, .NET 10, Android SDK 36, MAUI, xUnit</li>
<li><strong>Hosting &amp; CI/CD</strong>: Azure DevOps build &amp; release pipelines</li>
<li><strong>Deployment</strong>: Full responsibility for managing and verifying multi-app releases</li>
</ul>
<hr>
<h2>1. The Challenge</h2>
<p>With the release of Android 16 (SDK 36) and the availability of .NET 10, HWM required a comprehensive upgrade of its mobile and backend services to maintain store compliance, ensure API compatibility, and leverage performance optimizations.</p>
<p>Key challenges included:</p>
<ol>
<li><strong>Multi-App Orchestration</strong>: Upgrading the shared libraries and dependencies from .NET 9 to .NET 10 across multiple connected applications (Mobile App, Web APIs, and worker services) without causing breaking API mismatches.</li>
<li><strong>Android 16 Platform Deprecations</strong>: Targeting SDK 36, which introduced stricter background service execution limits, media permission constraints, and updated platform rendering behavior in MAUI.</li>
<li><strong>MAUI Compatibility</strong>: Troubleshooting runtime rendering differences and dependency conflicts between the new .NET 10 MAUI workload and legacy custom UI handlers.</li>
<li><strong>Regression Prevention</strong>: Ensuring all business-critical paths continued to function by writing comprehensive automated integration and unit test coverage.</li>
</ol>
<hr>
<h2>2. Technical Implementation &amp; Design Decisions</h2>
<ul>
<li><strong>System-Wide .NET 10 Upgrade</strong>: Led the migration of project files, packages, and build environments across multiple microservices and the MAUI app. Standardized package dependencies to eliminate version skew during build time.</li>
<li><strong>SDK 36 Integration &amp; Service Refactoring</strong>: Configured MSBuild project targets to build against SDK 36, and restructured background worker lifecycle handlers in the mobile app to comply with Android 16 background restrictions.</li>
<li><strong>Automated Testing Suite</strong>: Implemented xUnit test suites to validate MAUI platform handlers, API serialization, and service lifecycles to detect regressions early in the upgrade cycle.</li>
<li><strong>DevOps Pipeline Migration</strong>: Updated Azure DevOps YAML pipelines to use the .NET 10 SDK and SDK 36 build tooling, ensuring seamless CI/CD execution.</li>
</ul>
<hr>
<h2>3. Current Status &amp; Impact</h2>
<ul>
<li><strong>Upgrade PR Active</strong>: The consolidated multi-app upgrade PR is undergoing CI/CD verification and pipeline automated testing.</li>
<li><strong>Compliance &amp; Future Proof</strong>: Successfully positioned the mobile and backend ecosystem to support Android 16 devices on day one with maximum performance benefits from .NET 10.</li>
</ul>
