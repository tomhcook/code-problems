3:T8b1,<h1>PageRank Algorithm</h1>
<p>This problem was asked by Google.</p>
<p>PageRank is an algorithm used by Google to rank the importance of different websites. While there have been changes over the years, the central idea is to assign each site a score based on the importance of other pages that link to that page.</p>
<p>More mathematically, suppose there are $N$ sites, and each site $i$ has a certain count $C_i$ of outgoing links. Then the score for a particular site $S_j$ is defined as:</p>
<p>$$\text{score}(S_j) = \frac{1 - d}{N} + d \times \left( \frac{\text{score}(S_x)}{C_x} + \frac{\text{score}(S_y)}{C_y} + \dots + \frac{\text{score}(S_z)}{C_z} \right)$$</p>
<p>Here, $S_x, S_y, \dots, S_z$ denote the scores of all the other sites that have outgoing links to $S_j$, and $d$ is a damping factor, usually set to around 0.85, used to model the probability that a user will stop searching.</p>
<p>Given a directed graph of links between various websites, write a program that calculates each site&#39;s page rank.</p>
<h2>Difficulty: Hard</h2>
<h2>How the Solution Works</h2>
<p>We implement the <strong>Power Iteration</strong> method to calculate the PageRank:</p>
<ol>
<li><strong>Graph Representation:</strong> We represent the graph as an adjacency list of outgoing links.</li>
<li><strong>Dangling Nodes:</strong> Nodes with no outgoing links ($C_i = 0$) are treated as linking to all nodes in the graph to prevent the rank from leaking/disappearing.</li>
<li><strong>Iterative Update:</strong> <ul>
<li>Initialize the rank of all $N$ pages to $1/N$.</li>
<li>In each iteration, compute the new ranks based on the incoming ranks and distribute dangling node ranks equally.</li>
<li>Continue iterating until the ranks converge (i.e., the maximum change between iterations is below a threshold $\epsilon = 10^{-6}$), or up to a maximum number of iterations (e.g., 100).</li>
</ul>
</li>
</ol>
<h2>Complexity</h2>
<ul>
<li><strong>Time Complexity:</strong> $O(I \times (N + E))$ where $I$ is the number of iterations to convergence, $N$ is the number of websites (nodes), and $E$ is the number of links (edges).</li>
<li><strong>Space Complexity:</strong> $O(N + E)$ to store the graph and the ranks.</li>
</ul>
